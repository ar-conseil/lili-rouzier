Confidentialité

Ce que deviennent les informations que vous m’envoyez.

En bref

  • Aucun cookie, aucune mesure d’audience.
  • Je ne reçois que ce que vous m’envoyez par le formulaire.
  • Vos données servent seulement à vous répondre.
  • Elles sont gardées trois ans au plus sans collaboration.
  • Vous pouvez les consulter ou les faire supprimer à tout moment.

Ce que je collecte

Votre nom, votre entreprise, votre adresse e-mail, les réseaux concernés, votre message et, si vous le souhaitez, une idée de budget. Uniquement si vous remplissez le formulaire de contact.

Pourquoi

Pour vous répondre et, si vous le souhaitez, vous proposer un devis. Rien d’autre : pas de lettre d’information, pas de revente, pas de prospection.

Où vont vos données

Votre message passe par le service FormSubmit (formsubmit.co), qui me le transmet par e-mail. Il est ensuite conservé dans ma boîte mail.

Si vous m’écrivez sur WhatsApp ou si vous m’appelez, l’échange passe par ces services et par mon téléphone, comme n’importe quel message ou appel.

Combien de temps

Trois ans après notre dernier échange si nous ne travaillons pas ensemble. Si nous travaillons ensemble, le temps de notre collaboration, puis les durées imposées par la loi pour les documents comptables.

Vos droits

Vous pouvez à tout moment me demander d’accéder à vos données, de les corriger, de les supprimer ou d’en limiter l’usage. Écrivez-moi avec le formulaire de contact, je vous réponds dans un délai d’un mois au plus.

Si vous estimez que je ne respecte pas vos droits, vous pouvez vous adresser à la CNIL.

Cookies et mesure d’audience

Aucun. Ce site ne dépose aucun cookie et ne mesure pas votre visite : pas de Google Analytics, pas de pixel publicitaire.

Hébergement du site

Le site est hébergé par GitHub Pages. Comme tout hébergeur, GitHub peut enregistrer l’adresse IP des visiteurs pour la sécurité de son service.

Liens externes

Les liens vers Instagram, Facebook, LinkedIn, WhatsApp ou Google vous emmènent sur ces services, qui ont leurs propres règles.
